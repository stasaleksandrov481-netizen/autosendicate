# AutoSyndicate V16 — Garage Touch, Race UI, Inline Duels, Economy

## 1. Гараж / карусель

### Что исправлено
- Убрана конкуренция между горизонтальным свайпом карусели и вертикальным скроллом страницы.
- Добавлен отдельный pointer-drag слой `bindGarageCarouselV16()`.
- Направление жеста определяется только после небольшого порога движения.
- `pointer capture` включается только для подтверждённого горизонтального свайпа.
- Вертикальный жест остаётся браузеру (`touch-action: pan-y pinch-zoom`).
- Фото/SVG машины внутри media-блока больше не перехватывают pointer events и native drag.
- На время ручного drag отключается scroll-snap; после отпускания карусель плавно центрирует ближайшую машину.

### Как проверить
1. Открыть гараж на телефоне.
2. Провести пальцем влево/вправо по самой машине — карточки должны двигаться сразу и гладко.
3. Провести вверх/вниз прямо поверх карточки — страница должна нормально прокручиваться вертикально.
4. Нажать кнопки внутри карточки — кнопки должны работать, drag их не блокирует.

## 2. Гонки / визуализация

### Видимость участников
- Финальный race layer теперь использует participant-aware полосы.
- 2 участника: две отдельные полосы.
- 3 участника: три отдельные полосы.
- 4+ участников также получают раздельные lane-позиции.
- Добавлены реальные визуальные разделители полос.
- Даже если игрок и соперник находятся на одинаковой дистанции по X, они не перекрывают друг друга по Y.

### SVG вместо растровых машин
- В race HUD старые WebP/растровые изображения больше не используются финальным слоем.
- Игрок, NPC и ДПС рисуются компактными inline SVG-маркерами.
- SVG не перекрывает цифры прогресса и заметно легче для WebView.
- Полицейский маркер имеет отдельную красно-синюю световую идентификацию.

### Track Bar
- Дистанция вынесена в отдельную строку над progress bar.
- Полоса прогресса больше не конкурирует с цифрами за место.
- Зона машин физически отделена от HUD снизу.

## 3. ДПС / chase balance

### Исправлено
- Фора игрока остаётся 80 м.
- ДПС теперь начинает активное преследование с задержкой 1.15 сек, а не почти мгновенно.
- ИИ ДПС получил инерционную модель разгона.
- Скорость полиции зависит от:
  - текущей скорости игрока;
  - расстояния между машинами;
  - мощности автомобиля игрока;
  - качества переключений;
  - торможения / отпускания газа / ошибок игрока.
- Чем мощнее машина и чище езда, тем реальнее увеличить отрыв.
- При ошибках, торможении и плохом темпе полиция получает возможность закрыть gap.
- Поимка не может произойти в первые секунды погони.
- Поимка происходит только при фактическом закрытии дистанции.

### UI
- ДПС всегда виден отдельным SVG-маркером.
- В HUD показывается `ДПС · X м ПОЗАДИ`.
- Добавлен threat meter приближения ДПС.

## 5. Inline Mode

### Главный найденный баг
Старый код редактировал callback-сообщение только через `chat_id + message_id`. Telegram Inline Mode может присылать callback с `inline_message_id`, поэтому после `Принять дуэль` сообщение не редактировалось и интерфейс выбора машины не появлялся.

### Исправлено
- В Telegram callback type добавлен `inline_message_id`.
- Добавлен `editTelegramInlineMessage()`.
- Добавлен единый `editInlineCallbackMessage()`, который умеет работать и с обычным сообщением, и с настоящим inline message.

### Новый формат
Использование:

`@username_бота @username_соперника`

После ввода Telegram показывает список машин вызывающего игрока. Это нативный inline-results picker Telegram — отдельного HTML `<select>`/dropdown Telegram Bot API в inline-результатах не предоставляет.

### Новый flow
1. Вызывающий вводит `@bot @opponent`.
2. Получает список своих машин прямо в inline results.
3. Выбирает машину и отправляет карточку вызова в чат.
4. Кнопку `Принять дуэль` может нажать только указанный `@opponent`.
5. Если вызванный пользователь ещё не создал профиль или у него нет машин, inline-сообщение редактируется в:
   - `@username, у вас нет авто!`
   - `Перейдите в бота, чтобы купить первую машину и принять вызов.`
6. Если машины есть — прямо в этом же inline-сообщении появляется список машин соперника.
7. После выбора создаётся настоящая Race Room.
8. Сообщение превращается в карточку `AUTOSYNDICATE · RACE ROOM` с кнопкой входа.

### Защита
- Нельзя принять собственный вызов.
- Вызов привязан к конкретному username.
- После первого принятия выбор машины привязан к конкретному Telegram ID соперника.
- Callback data укладывается в лимит Telegram.

## 6. Race Rooms / live multiplayer progress

### База
Добавлена миграция:

`supabase/upgrade-v16-duel-live-progress.sql`

Она добавляет:
- `player_a_progress jsonb`
- `player_b_progress jsonb`

### Во время заезда
Каждый клиент примерно раз в 900 мс отправляет:
- distance;
- speedKmh;
- elapsedMs.

Сервер возвращает актуальный progress второго участника.

### Визуал
- В приватной дуэли маркер соперника на трассе двигается по его серверному progress, а не по локальной AI-симуляции.
- Оба игрока видят реальное положение друг друга.
- В комнате также добавлено отображение live distance/speed.

### Оптимизация
Progress endpoint использует отдельный lean path:
- один read комнаты;
- один update progress;
- без повторной загрузки профилей, гаража и каталога каждую секунду.

### Финиш
- Приватная Race Room работает на 402 м.
- После локального финиша UI сначала показывает `РЕЗУЛЬТАТ ОТПРАВЛЕН`.
- Игра ждёт результат второго участника.
- Победа/поражение затем заменяется серверно подтверждённым итогом Race Room.
- Локальная AI-оценка больше не выдаётся игроку за настоящий итог онлайн-дуэли.

## 7. Экономика

### Подработка снижена
Такси теперь является страховочным заработком, а не главным способом фарма.

Примерный масштаб:
- стартовая машина ~150 л.с.: такси около 1 400 SYND за ~16 сек;
- средняя ~500 л.с.: около 3 600 SYND за ~13 сек;
- топовая ~1 200 л.с.: около 11 700 SYND за ~7 сек.

Также снижены:
- рискованный перегон;
- пассивная смена эвакуатора.

### Гонки повышены
Новая базовая формула обычного заезда:

`max(24 000, 9 000 + power × 105 + level × 3 500)`

Боссы дополнительно получают множитель `1.55x`.

Пример:
- ~150 л.с. / lvl 1: около 28 250 SYND базовой награды;
- ~500 л.с. / lvl 5: около 79 000 SYND;
- ~1 200 л.с. / lvl 18: около 198 000 SYND.

Таким образом автоспорт снова существенно выгоднее безопасного такси.
