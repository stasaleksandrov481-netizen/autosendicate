# Обновление: система тегов игроков (мульти-теги)

## Что изменилось

Раньше игроку можно было выдать только один тег через `window.prompt()` в админке,
и он нигде толком не отображался вне админки. Теперь:

- **Несколько тегов на игрока** (до 6 одновременно) — например «Команда проекта» + «Разработчик».
- **11 готовых пресетов**: Специальный администратор, Команда проекта, Создатель проекта,
  Разработчик, Тестировщик, Модератор, Дизайнер, Тех. поддержка, Партнёр проекта,
  Ветеран проекта, VIP игрок.
- **Свой тег** — название, иконка (10 вариантов: шестерня, корона, щит, звезда, молния,
  кристалл, код, ключ, флаг, сердце), цвет фона и цвет текста через color-picker, свечение (glow).
- **Нормальный UI в админке** вместо prompt() — попап с готовыми тегами и конструктором
  своего тега с живым превью, доступен и в списке игроков, и на отдельной вкладке «🏷 Теги».
- **Теги видны везде**: чат, рейтинг (leaderboard), публичный профиль, свой профиль, состав клана.

## Шаги для запуска

1. **Выполни SQL-миграцию** в Supabase SQL Editor:
   `PROFILE_TAGS_MULTI_MIGRATION.sql` (добавляет колонку `profile_tags`, переносит старые
   значения из `profile_tag`, добавляет constraint на форму данных).
   Старая колонка `profile_tag` не удаляется — можно оставить как есть.

2. **Установи зависимости и собери проект** (в контейнере, где я работал, не было доступа
   в интернет, поэтому `npm install` не выполнялся — сделай это на своей машине/сервере):
   ```
   npm install
   npm run typecheck   # проверить, что всё собирается без ошибок
   npm run build
   ```

3. Задеплой как обычно.

## Где что лежит

- `src/features/tags/shared.ts` — общий модуль: типы, пресеты, иконки (SVG), нормализация,
  рендер бейджей. Используется и на сервере (валидация), и в клиентском runtime (отрисовка).
- `PROFILE_TAGS_MULTI_MIGRATION.sql` — миграция БД.
- `src/features/admin/schema.ts` / `server.ts` — новые admin-действия: `addTag`, `removeTag`,
  `setTags`, `clearTags` (вместо старых `setTag`/`clearTag`).
- `src/components/admin/AdminDashboard.tsx` — новый UI управления тегами (`TagBadgeView`,
  `TagPicker`).
- `src/legacy/runtime.ts` — везде, где раньше был `profileTagHTML(...)`, теперь
  `tagsRowHTML(...)` (рендерит несколько бейджей вместо одного).
- `src/app/globals.css` — стили `.tag-badge`, `.tags-row`, `.tag-badge-glow` и стили админ-панели
  (`.tag-picker-panel`, `.tag-icon-grid` и т.д.).

## Важно

Я не смог прогнать `npm install` / `npm run typecheck` / `npm run build` в этой сессии —
в моей рабочей среде нет доступа в интернет и не было `node_modules`. Я вручную перепроверил
все изменённые файлы (импорты, баланс скобок, соответствие типов), но перед деплоем
обязательно прогони `npm run typecheck` у себя — если где-то останется мелкая нестыковка,
это самый быстрый способ её поймать.
