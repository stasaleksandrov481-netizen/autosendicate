# AutoSyndicate V15.1 — Menu + Garage rebuild

## Навигация

- Пятая кнопка нижней навигации теперь **МЕНЮ**.
- Профиль остаётся доступен по аватару в шапке и по кнопке **ПРОФИЛЬ** внутри меню.
- В отдельном меню постоянно доступны:
  - Чаты
  - Кланы
  - Друзья
  - Кейсы
  - Рынок
  - Рейтинг
  - Банк
  - Рефералы
  - Чип-контракты
  - Настройки
- Профиль разгружен: в нём остаются карьерные разделы — районы, контракты, подработка, достижения, награда дня и shortcut в меню.
- Сервисные/социальные экраны возвращаются кнопкой `← Меню`, а не ведут пользователя обратно в свалку профиля.
- Badge непрочитанных сообщений привязан к видимой карточке «Чаты» в новом меню.

## Гараж

- Полностью перестроена композиция экрана под мобильный формат.
- Порядок блоков: заголовок → сортировка → основная карусель → компактный сервис.
- Центральная машина стала заметно крупнее; боковые машины остаются видимыми как часть карусели.
- Карточка автомобиля получила:
  - крупное изображение с `object-fit: contain`;
  - название/класс;
  - статус активной машины;
  - мощность;
  - топливо;
  - состояние;
  - госномер;
  - крупную основную кнопку выбора;
  - отдельные вторичные кнопки «Карточка» и «Номер».
- Старый громоздкий блок ТО заменён компактным сервисным доком для масла, шин и двигателя.
- Убран `touchmove.preventDefault()` из карусели, который мог блокировать вертикальный свайп страницы.
- Карусель использует `touch-action: pan-x pan-y pinch-zoom`, поэтому горизонтальное листание и вертикальная прокрутка страницы не конфликтуют.
