# AutoSyndicate Carbon — Economy / Work / UX / Gameplay Update 15

## Модуль 1 — глобальный ребаланс экономики

- Прайс-лист автомобилей переведён на крупный «рублёвый» масштаб без переименования валюты SYND / «Синдикат коины».
- Базовая лестница: ВАЗ-2106 — 60 000 SYND; Golf Mk2 — 320 000; AE86 — 850 000; спорт/премиум — миллионы; Bugatti Chiron — 280 000 000 SYND.
- Награды NPC-дуэлей теперь вычисляются по мощности и уровню соперника; взнос — около 10% награды, турниры имеют повышенную награду и взнос.
- Пересчитаны дневные награды, контракты, достижения, штрафы, лицензия и ряд других старых мелких сумм.
- Казино снова использует только SYND. Чипы из ставок удалены.
- Чипы оставлены отдельной редкой валютой: спец-погони, боссы и редкие контракты; траты — тюнинг/нитро/ТО/снижение розыска/восстановление прав.
- Исправлен баг, при котором серверный баланс 0 превращался в 1500 из-за `|| 1500`.
- API-валидация банковского перевода поднята до 250 000 SYND в соответствии с новым масштабом клиента.

## Модуль 2 — новая подработка

Обычная подработка теперь выдаёт только SYND.

### Такси
- Использует текущую активную машину.
- Есть визуальный маршрут с движущейся машиной и progress bar.
- Мощность и стоимость машины влияют на оплату.
- Мощность сокращает время выполнения заказа.

### Автоугон / перегон
- Повышенная выплата в SYND.
- Есть вероятность перехвата ДПС.
- При провале списывается штраф и увеличивается розыск.
- При успехе выплачивается повышенная награда.

### Эвакуатор
- Покупается один раз за 650 000 SYND.
- Пассивная 15-минутная смена.
- После завершения игрок вручную забирает SYND.
- Выплата растёт с уровнем игрока.

### Отдельный центр Чипов
- Вынесен из обычной подработки в отдельный экран «Чип-контракты».
- Редкая доставка деталей: +1 Чип, cooldown 30 минут.
- Дневной премиальный контракт за 3 редких доставки: +2 Чипа.
- Дополнительные источники: победа над боссом и успешная спец-погоня.
- Магазин Чипов: нитро, полное ТО, снижение розыска, возврат прав.

## Модуль 4 — гонки и багфиксы

### Невидимые машины
- Причина: часть rival-lane координат выходила за высоту `.cine-asphalt`, который имеет `overflow:hidden`.
- Все lane offsets перенесены внутрь дорожного viewport.
- Для player/NPC внедрены реальные изображения автомобилей через `.cine-vehicle-img-v15`.
- Принудительно закреплены `display:block`, `visibility:visible`, `opacity:1` и z-index гоночных машин.

### Кейсы
- Награда применяется сразу после подтверждённого server roll; анимация больше не является условием выдачи приза.
- Сохранён transition fallback примерно 2.2 секунды.
- Добавлен watchdog на 12 секунд: зависший `caseOpening` автоматически сбрасывается без перезапуска мини-аппа, после чего запускается reconcile серверной награды.

### Фантомные уведомления
- Удалён старый искусственный `Math.random()`-таймер, который самостоятельно увеличивал unread chat badge.
- Счётчик больше не генерирует уведомления «из воздуха».

### Разнообразие ИИ
- При построении списка NPC генерируются разные ники без повторов в текущем списке.
- Для NPC выбираются разные машины, близкие по мощности к сопернику.
- Выбранные имя/машина сохраняются на instance соперника и переносятся в сам заезд, поэтому карточка и трасса не расходятся.

### Оптимизация
- Убран лишний двойной слой рандомизации NPC.
- Сохранено ограничение DOM-HUD обновлений гонки до ~20 Hz при физике на `requestAnimationFrame`.
- Сохранён low-FX fallback при просадке frame time.
- Для cinematic race map добавлен CSS containment.
- Старые race RAF/timers очищаются через `cleanupRaceRuntimeV127` при выходе из гонки.
